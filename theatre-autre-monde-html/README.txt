THEATRE DE L'AUTRE MONDE — SITE HTML/CSS/JS

Ouvrir index.html dans un navigateur.
Chaque onglet correspond à une page HTML distincte :
- index.html
- spectacles.html
- entre-sort.html
- rue.html
- animations.html
- contact.html
- references.html

style.css contient les styles communs.
script.js gère le menu mobile et le formulaire (ouverture du logiciel mail via mailto).

Les images dans assets/ sont des recadrages des captures d'écran fournies.
Pour une reproduction fidèle, remplace-les par les fichiers originaux haute résolution.
Le contenu des pages autres que l'accueil et la page Rue est une proposition de structure
à compléter avec les textes et références exacts de la compagnie.
