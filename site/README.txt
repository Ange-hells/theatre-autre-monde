THEATRE DE L'AUTRE MONDE - reproduction responsive en HTML/CSS/JavaScript vanilla

Démarrage :
1. Décompresser le dossier.
2. Ouvrir le dossier dans un éditeur (VS Code par exemple).
3. Lancer index.html avec une extension de serveur local (Live Server recommandé).
   Les modules JavaScript ES nécessitent un serveur local dans certains navigateurs.
4. Chaque onglet possède son propre fichier HTML :
   index.html, spectacles.html, entre-sort.html, rue.html,
   animations.html, contact.html et references.html.

Architecture MVC :
- js/models/siteModel.js : contenu et données du site.
- js/views/siteView.js : génération du HTML des composants.
- js/controllers/siteController.js : orchestration et événements.
- js/app.js : point d'entrée.
- css/styles.css : styles et responsive.
- assets/images : visuels extraits des captures fournies.

À personnaliser :
- Les visuels fournis sont recadrés depuis les captures d'écran et peuvent être remplacés.
- Les textes des pages Spectacles, Entre-sort, Animations et Références sont des contenus de base à compléter.
- Le formulaire utilise mailto et ouvre le logiciel de messagerie du visiteur ; pour un vrai envoi web, connecter un backend.
- Vérifier et compléter les mentions légales avant publication.

Le bandeau Wix n'est pas reproduit.
